# Main Start Page – Wireframe Summary

## Purpose
사용자가 상담 과정을 시작하기 전에 서비스 목적을 이해하고,
프로젝트 아이디어를 입력한 뒤 대화형 상담 화면으로 이동하도록 안내하는 역할을 한다.

## Layout Structure
- Top Area
  - Title: "대화형 외주 개발 견적 상담"
  - Subtitle: 간단한 서비스 설명 문구
- Middle Area
  - Single-line TextField: 프로젝트 아이디어 입력창
- Bottom Area
  - Primary Button: "상담 시작하기"
- 전체 구성은 세로 중앙 정렬된 단일 컬럼 레이아웃

## UI Components
- Text: Main Title
- Text: Description
- TextField: Single-line Input
- Button: Primary Action
- Column Layout: Center aligned
- Page padding: 8px/16px 기반 Material spacing

## Style Guide
- Colors: Primary Blue, Navy, Light Gray 배경
- Typography: Material Design 3 기본 폰트
- Alignment: 수직 중앙 정렬
- Layout Grid: 8px spacing multiples
- Button: MD3 스타일의 Rounded Rectangle
